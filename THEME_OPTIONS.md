## 💻 **How to Apply a Theme**

### **Method 1: Quick Swap (Replace Color Palette)**
In `src/App.jsx`, change the `C` object:

```javascript
const C = {
  bg: "#ffffff",           // Change from #080d18
  panel: "#f5f7fa",        // Change from #0d1424
  panel2: "#eef2f8",       // Change from #111a30
  line: "#e0e7ff",         // Change from #1e2a45
  ink: "#1a202c",          // Change from #e8eefc
  muted: "#718096",        // Change from #7e8db5
  teal: "#0ea5e9",         // Keep or change
  purple: "#7c3aed",       // Keep or change
  pink: "#ec4899",         // Keep or change
  blue: "#3b82f6",         // Keep or change
  green: "#10b981",        // Keep or change
  amber: "#f59e0b",        // Keep or change
  red: "#ef4444",          // Keep or change
};
```

### **Method 2: Create Theme File**
Create `src/themes.js`:

```javascript
export const themes = {
  darkModern: { /* Option 1 */ },
  lightPro: { /* Option 2 */ },
  medical: { /* Option 3 */ },
  // ...
};

// Then switch:
const [currentTheme, setCurrentTheme] = useState('darkModern');
const C = themes[currentTheme];
```

### **Method 3: CSS Variables**
Update `src/styles.css`:

```css
:root {
  --bg: #ffffff;
  --panel: #f5f7fa;
  --ink: #1a202c;
  /* ... etc */
}

/* Usage in React */
background: var(--bg);
color: var(--ink);
```
